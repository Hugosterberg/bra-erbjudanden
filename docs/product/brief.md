# Produktbrief — braerbjudanden.se

## Vision

`braerbjudanden.se` ska bli en modern svensk sajt för bra erbjudanden, rabatter och kampanjer. Den ska kännas enklare, smartare och mer premium än traditionella rabattkodssidor.

## Målgrupp

Personer i Sverige som vill hitta bra erbjudanden snabbt utan att leta runt på många olika sajter.

## Värdelöfte

Hitta bra erbjudanden snabbt, presenterade på ett enkelt och trovärdigt sätt.

## Primära användarflöden

1. Besökare kommer till startsidan.
2. Besökare ser utvalda/rankade erbjudanden.
3. Besökare klickar på ett erbjudande.
4. Klicket registreras.
5. Besökare skickas vidare via affiliatelänk eller butikslänk.

## Adminflöden

1. Admin loggar in.
2. Admin skapar eller redigerar butik.
3. Admin skapar erbjudande.
4. Admin väljer rabattkod eller direktlänk.
5. Admin anger rabatt: procent eller fast belopp.
6. Admin sätter manuell ranking.
7. Admin publicerar erbjudandet.
8. Admin följer klickstatistik.

## Lanseringsscope

Bygg först en stabil MVP med:

- Startsida
- Erbjudandelista
- Erbjudandekort
- Butikssidor
- Kategorier
- Adminpanel
- Klickspårning
- Manuell ranking
- Supabase-databas
- SEO-grund

## Inte i första versionen

- Kundkonton
- Betalningar
- Användargenererade erbjudanden
- Avancerade personaliserade rekommendationer
- Komplexa lojalitetsprogram
