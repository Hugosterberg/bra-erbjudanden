# Rekommenderad byggordning

1. Skapa Next.js-projekt med TypeScript, Tailwind och App Router.
2. Installera och konfigurera shadcn/ui.
3. Skapa grundlayout, font, metadata och designsystem.
4. Skapa Supabase-klienter och miljövariabler.
5. Skapa databasmigrationer för stores, categories, offers och click_events.
6. Skapa publika queries för publicerade erbjudanden.
7. Bygg startsida med rankade erbjudanden.
8. Bygg erbjudandekort.
9. Bygg `/go/[offerId]` för klickspårning och redirect.
10. Bygg admin-auth och skyddade adminrutter.
11. Bygg admin-CRUD för erbjudanden.
12. Bygg rankinghantering.
13. Bygg enkel klickstatistik.
14. Lägg till SEO, sitemap och robots.
15. Förbättra polish, tomma states, loading states och felhantering.
