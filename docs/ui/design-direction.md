# Designriktning

## Känsla

Sidan ska kännas:

- Premium
- Smart
- Modern
- Enkel
- Trovärdig
- Konverteringsfokuserad

## Undvik

- Blinkande rabattbanners
- För många färger
- Stökiga listor
- Aggressiv casino/e-handel-känsla
- För många filter i första versionen
- Billig kupongsida-känsla

## UI-principer

- Mobil först.
- Tydlig hierarki.
- Mycket whitespace.
- Stora klickytor.
- Korta texter.
- Få men tydliga CTA:er.
- Erbjudandet ska vara lätt att förstå på några sekunder.

## Visuell riktning

Använd en ljus eller mjukt varm premiumbas, med mörka texter och tydliga accentfärger. Undvik för skrikiga kampanjfärger.

Möjliga känslor:

- Fintech
- Premium marketplace
- Editorial commerce
- Smart shopping assistant

## Exempel på svensk copy

- “Dagens bästa erbjudanden”
- “Utvalda rabatter”
- “Handplockade deals”
- “Spara mer utan att leta”
- “Visa erbjudande”
- “Kopiera kod”
- “Gå till butik”
- “Gäller till”
