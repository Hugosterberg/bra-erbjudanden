# Prompt: bygg admin

Bygg adminflödet för `braerbjudanden.se`.

Admin ska kunna:

- Logga in
- Se erbjudanden
- Skapa erbjudande
- Redigera erbjudande
- Publicera erbjudande
- Arkivera erbjudande
- Ändra manuell ranking
- Se antal klick per erbjudande

Följ vertical slice architecture och lägg adminrelaterad kod i relevanta features.

Använd Supabase Auth och skydda alla adminrutter.
