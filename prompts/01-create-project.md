# Prompt: skapa projektet

Skapa ett nytt repo för `braerbjudanden.se` enligt alla instruktioner i detta repo.

Läs först:

- AGENTS.md
- docs/product/brief.md
- docs/product/requirements.md
- docs/domain/model.md
- docs/architecture/architecture.md
- docs/architecture/supabase.md
- docs/ui/design-direction.md
- docs/workflows/build-order.md

Bygg sedan upp projektet stegvis.

Krav:

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase
- Vertical slice architecture
- Svensk UI-copy
- Engelska namn i kod och filstruktur
- Premium, enkel och modern känsla
- Admin-only första versionen
- Manuellt rankade erbjudanden
- Klickmätning per erbjudande

Skapa inte onödiga funktioner utanför MVP-scope.

När du är klar, sammanfatta:

1. Vad du skapade.
2. Hur man kör projektet lokalt.
3. Vilka miljövariabler som krävs.
4. Vilka delar som är mockade eller behöver riktiga Supabase-uppgifter.
